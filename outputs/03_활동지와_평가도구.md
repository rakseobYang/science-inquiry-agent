# 학생 활동지와 평가·연구 도구

중1 자유학기 과학 공방 · 출력·복사 가능한 원본 · 적용 전 초안

## 교사 사용 안내

활동지는 학생 개인 기록과 모둠 공동 자료를 구분한다. 연구에 동의하지 않은 학생도 동일한 수업과 피드백을 받는다. 동의하지 않은 학생의 응답·작품·관찰 기록은 연구용 데이터로 전환하지 않는다. 아래 설문·과제는 자체 제작 초안으로, 검증된 흥미 척도 또는 표준화 검사가 아니다. 문항 이해·내용 적합성 검토 후 사용한다. 모든 표의 데이터 칸은 실제 측정 전까지 빈칸으로 유지한다.

## 연구 도구 A. 사전·사후 공통 설문

연구코드 ___ / □ 사전 □ 사후 □ 선택 추적 / 날짜 ___

‘평소의 나’를 생각해 표시한다. 1 전혀 그렇지 않다, 2 그렇지 않다, 3 보통이다, 4 그렇다, 5 매우 그렇다. 응답하고 싶지 않으면 빈칸으로 둔다. 정답은 없고 교사 평가·수업 참여에 영향을 주지 않는다.

| 번호 | 문항 | 1~5 |
| --- | --- | --- |
| A1 | 나는 과학 현상을 직접 조사해 보는 활동에 관심이 있다. |  |
| A2 | 나는 과학 수업에서 생긴 궁금증을 더 알아보고 싶다. |  |
| A3 | 과학 탐구는 생활 속 현상을 이해하는 데 도움이 된다고 생각한다. |  |
| A4 | 관찰한 근거로 생각을 설명하는 일은 가치 있다고 생각한다. |  |
| A5 | 기회가 있다면 새로운 과학 실험에 다시 참여하고 싶다. |  |
| A6 | 나는 내가 정한 과학 질문을 조사해 보고 싶다. |  |

A1~2 관심, A3~4 가치, A5~6 재참여 의향으로 각각 요약하며 문항별 분포를 함께 보고한다. 최소 분석용 개념 묶음이며 검증된 하위척도라고 부르지 않는다.

## 연구 도구 C. 평행형 탐구 설명 과제

아래 수치는 **과제용으로 만든 가상 자료**이며 실제 수업 결과가 아니다. 학생에게도 가상 자료임을 알린다. 각 과제는 약 7분을 배정한다. 사전·사후 A/B 순서를 학생별로 번갈아 배정한다.

### 과제 A: 낙하 모형 비교

같은 모형에 덮개 A 또는 B를 달아 같은 높이에서 놓았다. 추, 실 길이, 장소는 같았다. A의 낙하시간은 1.0, 1.1, 1.0초이고 B는 1.4, 1.3, 1.5초였다.

1. 이 조건에서 더 오래 떨어진 덮개는 무엇인가? ___
2. 판단에 사용한 수치를 2개 이상 적어라. ___
3. 반복해서 측정한 이유와 같은 조건을 유지한 이유를 설명하라. ___
4. ‘B는 어떤 높이와 바람에서도 더 오래 떨어진다’고 말해도 되는가? 추가 확인 조건을 적어라. ___

### 과제 B: 종이 구조 비교

같은 길이·재료의 종이 구조 A와 B에 같은 방식으로 작은 하중을 올렸다. 휘어지기 시작한 하중은 A에서 20, 25, 20g이고 B에서 35, 30, 35g이었다. 받침 간격과 놓는 위치는 같았다.

1. 이 조건에서 더 큰 하중을 견딘 구조는 무엇인가? ___
2. 판단에 사용한 수치를 2개 이상 적어라. ___
3. 반복해서 측정한 이유와 같은 조건을 유지한 이유를 설명하라. ___
4. ‘B는 어떤 받침 간격과 재료에서도 더 큰 하중을 견딘다’고 말해도 되는가? 추가 확인 조건을 적어라. ___

채점 공통: 두 과제 모두 B가 해당 조건에서 더 높은 측정값을 보인다는 판단이 가능하다. 실제 자료 사용, 공정한 비교·반복의 이유, 일반화 한계가 평가 대상이다. 물리 공식 암기를 요구하지 않는다. 두 과제의 동등성은 사전 검토 전 미확정이다.

## 공통 설명 루브릭

| 항목 | 0점 | 1점 | 2점 |
| --- | --- | --- | --- |
| 주장 | 무응답 또는 자료와 모순 | 방향은 맞지만 조건·대상이 불분명 | 자료와 일치하고 해당 조건의 범위를 밝힘 |
| 근거 | 자료 없음·조작 | 관찰/수치 1개 또는 막연한 비교 | 관련된 관찰/수치 2개 이상으로 비교 |
| 이유 | 근거-주장 연결 없음 | 부분적 설명 | 과학 개념 또는 비교·반복의 이유로 명확히 연결 |
| 한계·수정 | 무조건 일반화·무응답 | 오차·조건을 막연히 언급 | 구체적 한계와 필요한 재확인·수정 제시 |

총 0~8점. 활동지의 이유 항목은 해당 영역 개념을, 평행형 과제에서는 공정한 비교·반복을 평가한다. 활동지 서로 간 점수와 평행형 점수가 같은 난이도라고 간주하지 않는다. 미술적 솜씨는 채점하지 않는다.

## 선택 면담 질문

1. 가장 더 알아보고 싶어진 활동과 이유는 무엇인가? 재미와 궁금증이 서로 달랐던 활동도 있었는가?
2. 실험·장비·기록·모둠 역할 중 어려웠던 점은 무엇인가? 어떤 도움이 필요했는가?
3. 세포 모형/열쇠고리를 만든 뒤 무엇을 설명할 수 있게 되었는가? 아직 모르는 점은 무엇인가?
4. 수업이 시작되기 전과 비교해 다시 실험하려는 생각이 달라졌는가? 달라지지 않았다면 이유는 무엇인가?
5. 이 수업에서 한 가지를 바꾼다면 무엇을 바꾸고 싶은가?

면담은 동의를 받아 별도로 실시하고, 거절해도 불이익이 없음을 안내한다. 녹음 없이 교사 메모로 진행할 수 있으며 인용 시 학생 확인을 받는다.

## 연구 데이터 입력 형식

개인 관심 설문: `코드, 시점, 날짜, A1~A6`. 즉시 흥미: `코드, 영역, 날짜, B1~B3, 이유`. 탐구 과제: `코드, 시점, 형식A/B, 주장, 근거, 이유, 한계, 채점자`. 모둠 실험: `모둠코드, 영역, 조건, 시행, 측정값, 단위, 실패여부, 메모`. 참가 동의·신원 대응표는 이 파일들과 분리 보관한다.

입력 점검: 1~5 외 설문값은 원본 확인, 무응답은 빈칸, 초·cm·m 등 단위 통일, 가상 과제 수치를 실제 학생 실험 자료에 입력하지 않기, 실패 시행과 정상 시행 구분, 사전·사후 형식 기록. 학생 개인 자료와 모둠 자료를 섞어 표본 수를 늘리지 않는다.

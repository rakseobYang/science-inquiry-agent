# 범용 연구계획서 에이전트와 과학 수업 설계

연구아이디어를 선행연구 검색·자기점검을 거쳐 연구계획서로 발전시키는 Codex용 Markdown 지침과, 중학교 1학년 자유학기 과학 주제선택 프로그램 초안입니다.

## 구성

- [연구계획서](outputs/01_연구계획서.md)

- [활동지와 평가 도구](outputs/03_활동지와_평가도구.md)
- [논문 검색과 자기점검](outputs/04_논문검색과_자기점검.md)

## 사용

Codex에서 프로젝트 폴더를 열고 다음과 같이 요청합니다.

> outputs/research-proposal-agent.md를 읽고 내 연구아이디어를 바탕으로 연구계획서를 작성해줘. 선행연구 검색 기록과 자기점검 결과도 포함해줘.

수업 자료는 45분×16차시, 학생 24명을 가정한 적용 전 초안입니다. 실제 운영 조건과 교육과정, 예비 실험, 연구 동의 절차를 확인하여 조정하세요. 평가 도구는 자체 제작 초안이며 검증된 표준화 척도가 아닙니다.
